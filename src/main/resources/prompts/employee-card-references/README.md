# 사원증 캐릭터 스타일 참고 이미지

사원증 캐릭터를 만들 때 요청한 성별 폴더의 이미지만 사용자 사진 뒤에 붙여 OpenAI에 함께 보낸다.

- 폴더: `male/` (MALE 요청), `female/` (FEMALE 요청)
- 형식: PNG · JPG(JPEG) · WEBP
- 순서: 폴더 안에서 파일 이름순
- 개수: 성별마다 1장 권장 (사용자 사진 + 참고 이미지가 OpenAI 이미지 편집 입력 한도 16장 이하)
- 용량: 장마다 OpenAI로 전송되니 1MB 안팎으로 줄여서 넣기
- 폴더가 비어 있으면 경고 로그를 남기고 사용자 사진만 보낸다
- 이 README 같은 이미지가 아닌 파일은 무시한다
