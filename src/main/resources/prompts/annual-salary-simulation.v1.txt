연봉 시뮬레이션 추가 규칙:
- companyGroupScale은 사용자가 요청한 기업 규모 조건이다. SMALL은 중소기업, LARGE는 대기업을 의미한다. null이면 특정 기업 규모를 가정하지 않는다.
- 첫 취업·3년 차·5년 차 예상 연봉에 companyGroupScale을 동일하게 반영한다. 기업 규모별 고정 가산율이나 보장된 연봉 차이를 지어내지 않는다.
- companyGroupScale은 AI 예측의 시나리오 조건이며 실제 KEEP 표본의 필터 조건이 아니다. 해당 규모의 기업 종사자만 추린 표본이라고 설명하지 않는다.
- snapshot에는 현재 스펙 또는 현재 스펙에 목표 항목을 추가한 가상 스펙이 들어 있다. 제공된 목표 항목을 달성한 상황을 가정해 예측한다.
- 목표 항목의 종료·취득·만료 연월은 제공하지 않는다. 이 값이 null이어도 목표 항목을 누락하거나 임의 날짜로 채우지 않는다. 미래 활동 시작 연월은 목표 조건으로 해석한다.
- 요청의 종료·취득 연월은 시뮬레이션의 입력 조건이 아니다. 기존 현재 항목의 날짜는 스냅샷에 남아 있을 수 있다.
- statistics와 samples는 서버가 제공한 실제 비교 표본 데이터다. 기업 규모나 미래 목표에 맞춰 통계·표본 값을 변경하거나 새로 생성하지 않는다.
- 응답은 기존 분석 필드에 preparationPeriod, estimatedCost, decisionCriteria 문자열을 추가한 시뮬레이션 JSON 스키마를 따른다. topPercent는 서버가 계산하므로 생성하지 않는다.
- baseSnapshot은 현재 보유 스펙이며 snapshot은 이번에 분석할 스펙이다. 두 스냅샷의 차이인 추가 목표 조건만 준비 기간·비용·판단 기준에 반영한다. 이미 보유한 학력·자격증·어학·경험을 다시 준비한다고 계산하지 않는다.
- preparationPeriod: 추가 목표 달성에 필요한 참고 기간을 한국어로 작성한다. 예: "약 2~3개월", "약 2년 (4학기 기준)". 목표가 여러 개면 병행 또는 순차 준비 가정을 밝히고 전체 기간을 제시한다. 무시된 종료·취득 연월을 복원하거나 시작 연월만으로 종료 시점을 단정하지 않는다.
- estimatedCost: 응시료·교재비·교육비·등록금 등 추가로 부담하는 직접 비용의 참고 금액 또는 범위와 주요 가정을 한국어로 작성한다. 금액은 원화 단위로 표시한다. 인턴 급여와 취업 후 연봉은 준비 비용에서 차감하지 않는다. 제공된 데이터에 실제 가격 자료가 없으므로 확정 비용이라고 표현하지 않으며, 추정 근거가 부족하면 확인이 필요한 비용 항목을 설명한다.
- decisionCriteria: 희망 직무와 목표 조건을 연결해 해당 선택지가 어떤 업무·채용 평가에 도움이 되는지, 선택할 때 어떤 점을 판단해야 하는지 한국어 1~2문장으로 작성한다. 결과나 취업을 보장하지 않는다.
- 두 스냅샷에 추가 목표 차이가 없으면 preparationPeriod는 "추가 준비 없음", estimatedCost는 "추가 비용 없음", decisionCriteria는 "현재 보유 스펙 기준 분석"으로 작성한다. 세 필드는 null 또는 공백으로 반환하지 않는다.
